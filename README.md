# Container files Repository

This is a repo to hold various container files for images I create.

## TeX Live

- Auto **update the 1st day in every month**
- Based on Debian latest image
- Platform: amd64
- Languages: Chinese, English
- Only support LaTeX, not ConTeXt

You can use command `docker pull ghcr.io/<my_github_username>/texlive:latest` to pull the latest version.

_Note_: If you wish to use the latest version of TeXLive **Official Image**, you can pull it by running `docker pull texlive/texlive:latest`.
